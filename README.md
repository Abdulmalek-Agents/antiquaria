# 🔍 Antiquaria — ⚠️ DEPRECATED (2D concept)

> **This 2D concept has been halted.** Studio direction shifted to 3D-native projects with bigger teams and 2-year ship windows. See [`DEPRECATED.md`](DEPRECATED.md) for full rationale.

## What happened

Antiquaria was greenlit by the 14-expert Portfolio Review Board in May 2026 as a low-budget, 1-year 2D shippable concept (8.43/10 average). After founder review, the studio committed to **3D-native projects only**. Antiquaria's design strengths (cozy deduction, tactile pinboard) are inherently 2D-shaped and don't translate cleanly to 3D — the Board unanimously chose to **deprecate this concept rather than force a 3D port**.

## What's still here

The full v0.1 design is preserved in git history:

- 14-expert board approval audit trail
- Marketing plan + asset plan + production plan

Feel free to fork as a historical reference. **No new development is planned here.**
